# MBG Football Community Website ⚽

MBG Football Community Website is a web-based platform designed to support football community engagement through club information, news, events, and member interaction in a modern and responsive interface.

## Features
- Homepage / Landing Page
- Community Profile
- News & Updates
- Events / Match Schedule
- Gallery
- Membership Information
- Contact Page
- Responsive Design

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Laravel (if using Laravel Blade)

## Installation

Clone repository:

```bash
git clone https://github.com/Aldianfa/MBG-Football-Community-Website.git
```

Move into project folder:

```bash
cd MBG-Football-Community-Website
```

Install dependencies (if Laravel):

```bash
composer install
```

Copy environment file:

```bash
cp .env.example .env
```

Generate application key:

```bash
php artisan key:generate
```

Run development server:

```bash
php artisan serve
```
